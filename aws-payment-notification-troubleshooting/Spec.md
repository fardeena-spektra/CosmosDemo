AWS Payment Notification Troubleshooting

Lab Overview
• Cloud: AWS
• Duration: 90 minutes
• Exercises: 3 (Repair the PAYNOTIFY Statements Bucket, Repair the PAYNOTIFY Notification Function, Review the PAYNOTIFY Network Basics)
• Validations: 2
• Deployed services: CloudFormation, EC2 Windows Server 2022 Virtual Machine, Amazon VPC networking, Amazon S3 bucket, AWS Lambda function, IAM roles and policies
• Scenario: The learner acts as the on-call engineer for the failing fintech PAYNOTIFY payment-notification service in us-east-1. Working from a Windows VM over RDP over HTTPS, the learner repairs a deliberately misconfigured S3 bucket and Lambda function, proves statement uploads and notification writes, and answers six networking questions.
