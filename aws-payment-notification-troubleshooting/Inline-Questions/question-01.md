## Question
During troubleshooting, an engineer reviews the PAYNOTIFY VPC and finds that the `10.10.1.0/24` subnet is associated with one Availability Zone. Which statement correctly describes the scope of an AWS subnet?

## Options
Option 1 : A subnet can span multiple Availability Zones within the same VPC.
Option 2 : A subnet belongs to one Availability Zone and cannot span Availability Zones.
Option 3 : A subnet must use the same CIDR block as the entire VPC.
Option 4 : A subnet can contain address ranges from multiple VPCs.

## Answers
Option 2

## Correct Answer Feedback
Option 2 is correct answer, an AWS subnet is a range of IP addresses within a VPC and is scoped to a single Availability Zone.

## Incorrect Answer Feedback
Selected Option is not correct Option 2 is the correct answer. An AWS subnet cannot span Availability Zones.
